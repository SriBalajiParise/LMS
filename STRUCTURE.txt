╔══════════════════════════════════════════════════════════════════════╗
║                    DATA STRUCTURES USED                              ║
╚══════════════════════════════════════════════════════════════════════╝

1. 🗂️  HASHMAP (Java Collections)
   ├─ Location: BookService.java, UserService.java
   ├─ Purpose: Fast lookup by ID
   ├─ Operations: O(1) insert, search, delete
   └─ Storage: Books by ID, Users by ID

2. 🌳  BINARY SEARCH TREE (Custom Implementation)
   ├─ Location: BookBST.java, BSTNode.java
   ├─ Purpose: Sorted book storage & title search
   ├─ Operations: O(log n) insert, search
   └─ Features: In-order traversal for sorted list

3. 🔗  LINKED LIST (Custom Implementation)
   ├─ Location: BorrowRecordList.java, Node.java
   ├─ Purpose: Sequential borrow history
   ├─ Operations: O(1) append, O(n) search
   └─ Features: Generic Node<T> implementation

4. 📊  SORTING ALGORITHMS
   ├─ Merge Sort: O(n log n) - Stable sorting
   └─ Quick Sort: O(n log n) avg - Alternative
