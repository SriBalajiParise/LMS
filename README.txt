LIBRARY MANAGEMENT SYSTEM
=========================

COMPILE & RUN:
  javac LibrarySystem.java
  java LibrarySystem

FEATURES:
- Book Management (Add, Update, Delete, Search)
- User Management (Register, Update, Delete)
- Borrowing System (Borrow, Return, Track)
- Statistics & Reports

DATA STRUCTURES:
- HashMap for O(1) book/user lookup
- Binary Search Tree for sorted searching
- Linked List for borrow history
- Merge Sort for sorting results

SAMPLE DATA:
- 5 books pre-loaded
- 3 users pre-loaded

QUICK TEST:
1. Run program
2. Option 10 (Borrow): User U001, Book B001
3. Option 12 (History): User U001
4. Option 11 (Return): Book B001
